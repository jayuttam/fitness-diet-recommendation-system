# Fitness & Diet Recommendation System

A full-stack **MERN + Machine Learning** application that provides personalized **calorie intake, diet plans, and workout recommendations** based on user physical attributes and fitness goals.

## 🚀 Features
- Personalized calorie prediction using **Linear Regression**
- Diet and workout recommendations using **Decision Tree classification**
- Interactive frontend built with **Vite + React**
- REST API–based integration between ML models and MERN backend
- Scalable architecture for future fitness parameter expansion

## 🧠 Machine Learning Models
- **Decision Tree (Classification):** Determines diet category and workout type based on user inputs
- **Linear Regression:** Predicts daily calorie requirements for fat loss and muscle gain

## 🛠 Tech Stack
- **Frontend:** Vite, React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Machine Learning:** Python (scikit-learn)  
- **Integration:** REST APIs

## 📥 Inputs
- Height
- Weight
- Fitness Goal (Fat Loss / Muscle Gain)

## 📤 Outputs
- Daily calorie recommendation
- Diet plan suggestion
- Workout routine recommendation

## 🔮 Future Enhancements

- User authentication and profile tracking
